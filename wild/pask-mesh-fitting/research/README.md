# Pask Mesh Fitting Research

This directory contains the theoretical foundation for Pask Mesh Fitting — the mechanism by which an unprovenanced document fragment is structurally evaluated against a trusted corpus mesh to detect contradiction and "type-spoofing" (disinformation).

- **[Research Survey](research-survey.md)** — Consolidated treatment of six mathematical/computational frameworks: knowledge graph embeddings, sheaf theory, LLM-based extraction, topological data analysis, graph matching, quantum probability (Bradley), and adjacent frameworks.
- **[Tractability, Complexity, and Risk](tractability-and-risks.md)** — Core assumptions and their vulnerabilities, scaling bottlenecks ($O(N^3)$), "kill-or-cure" validation experiments, and scoped-down fallbacks.
