Ideas and notes collected from the talk **"No Vibes Allowed: Solving Hard Problems in Complex Codebases"** by Dex Horthy (HumanLayer), presented at the AI Engineer Code Summit, November 2025.

## Source Video

- 🎬 [No Vibes Allowed: Solving Hard Problems in Complex Codebases – Dex Horthy, HumanLayer](https://www.youtube.com/watch?v=rmvDxxNubIg) *(AI Engineer Code Summit, 2025)*

## Presenter

**Dex Horthy** — Founder & CEO of [HumanLayer](https://www.humanlayer.dev/)

HumanLayer builds tooling for AI coding agents, including **CodeLayer**, an open-source agentic IDE for orchestrating coding agents at scale. They coined the term "Context Engineering" and developed the 12-Factor Agents framework.
