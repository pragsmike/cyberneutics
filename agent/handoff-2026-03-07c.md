## Mistakes and Lessons

### Context compression causes "file not read" errors

When making many edits across many files in a single session, earlier Read tool results get compressed out of context. The Edit tool then refuses with "File has not been read yet." Re-reading the relevant lines before each edit batch is necessary.

**Lesson**: When editing many files, batch reads immediately before the corresponding edits rather than reading everything up front.

### replace_all is powerful but needs verification

Using `replace_all: true` to fix all occurrences of `agent/scenarios/methodology-adoption-strategy/` worked cleanly, but required a follow-up read to verify YAML front matter and prose were both updated correctly.

**Lesson**: After `replace_all`, read back the file to confirm no unintended replacements or remaining instances.
