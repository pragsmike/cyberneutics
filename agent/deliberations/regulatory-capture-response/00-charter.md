# Charter: Responding to Regulatory Capture Coercion

## Decision Question

Crock's regulatory capture is active and the compliance deadline approaches. Glenda's organization must decide how to respond — comply, resist, go public, build coalitions, or some combination — knowing that the choice shapes which of the four mapped futures materializes.

The committee deliberates across the scenario set to identify what Glenda's organization should do *now*, before committing to any single path.
