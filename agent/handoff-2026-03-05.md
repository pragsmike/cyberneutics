The core intellectual contribution of this session is the two-axis taxonomy:

|  | Single model | Multi-model |
|---|---|---|
| **Shared context** (roleplay) | Current baseline | Not meaningful |

## Technical Notes

- **pcrit-llm API shape**: `(call-model "openai/gpt-4o" "prompt string")` returns `{:content "..." :generation-metadata {:model, :provider, :token-in, :token-out, :cost-usd-snapshot, :duration-ms}}`. Currently takes a single prompt string, not a message sequence — this may need extension for multi-turn committee deliberation.

- **LiteLLM v1.65.0 is an MCP Gateway**: No wrapper needed for Tier 2.5. This was discovered in the research results and is reflected in the taxonomy's MCP considerations section.

- **Agent Teams spawn mechanics**: Teammates are spawned with a prompt that becomes their system context. For committee use: put the character brief + Robert's Rules instructions + topic in the spawn prompt. Teammates communicate via `SendMessage` tool (file-based mailbox). Can specify model per teammate (Opus/Sonnet/Haiku).

- **No pure Clojure agent framework exists**: The research survey found nothing. Closest options: Agent-o-rama (Clojure library for building agents) + LangChain4j, or Nubank pattern (Clojure + LiteLLM via Python interop). For the Tier 3 orchestrator, a bespoke Clojure process using pcrit-llm is the right path — an "agent framework" is overkill for what is fundamentally a fold.

- **The `wild/` research results document should stay in `wild/`**: mg explicitly said to leave it there. It's a reference, not methodology. The taxonomy document cites it for specifics.

## Theoretical/Conceptual Notes

- **The key insight of this session**: Model diversity and agent independence are orthogonal axes, not a single spectrum. The current roleplay baseline scores (0, 0) on both. Tier 1 moves along the independence axis alone. Tier 3 moves along the diversity axis alone. The fact that these can be tested independently is what makes the research program tractable.

- **"Performed disagreement" vs. "emergent disagreement"**: In roleplay, one model simulates conflict — it generates and suppresses its own tendencies simultaneously. With independent agents, disagreement can emerge from architectural separation even without model diversity, because each agent develops positional commitments in isolation before encountering others' arguments. Whether this distinction matters empirically is the Tier 1 experiment's core question.

- **The accessibility gradient is a design value**: Tier 1 (anyone with the product) → Tier 2.5 (power users with LiteLLM) → Tier 3 (developers with Clojure). The methodology should work at every level, with quality improving as users invest more infrastructure. This parallels the methodology's general principle: unreliable primitives composed into reliable systems.
