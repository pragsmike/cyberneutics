## Mistakes and Lessons

1. **First remediation plan over-corrected on §5c.** The initial rewrite still framed soft types as "initial C-algebras" — the subagent reviewer caught this as introducing the same conflation in different language. Lesson: when fixing a type error in mathematical text, check that the replacement doesn't make the same category mistake at a different level.

2. **Worked example needed more scaffolding than anticipated.** The plan initially specified "exhibit the presheaf" without specifying the type lattice T, the rubric function, or an example artifact. The subagent reviewer flagged this as under-specified. Lesson: a mathematical worked example requires defining its domain objects explicitly, not assuming the reader will fill in from context.

3. **Markov axiom verification was flagged as partially resolved.** The Chapman-Kolmogorov composition was exhibited but full axiom verification (associativity, identity laws) was deferred as consistent with "provisionally useful but untrusted" epistemic status. This is acceptable but should be noted for the ACT outreach.
