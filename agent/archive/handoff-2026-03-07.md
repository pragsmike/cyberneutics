## Mistakes and Lessons

### Tooling issue: `apply_patch` was unavailable

The `apply_patch` tool failed repeatedly with no useful error output, including on trivial test patches. To keep the session moving, file edits were done through direct workspace writes with explicit UTF-8-no-BOM writes via PowerShell/.NET.

**Lesson**: If `apply_patch` is nonfunctional in this environment, switch quickly to direct writes rather than burning time retrying. Keep batches small and verify after each batch.

### Shell batching was too optimistic at first

The first attempt to write many files in one shell call kept hitting the timeout. Splitting the work into smaller, targeted writes was more reliable.

**Lesson**: In this shell, large here-string write batches are riskier than several smaller deterministic writes.

### Python launcher mismatch

`python` was not available on PATH, but `py -3` worked.

**Lesson**: On this machine, validation commands should use `py -3`, not `python`.
