## Mistakes and Lessons

### `apply_patch` is still broken

`apply_patch` failed again in this session with no usable error output, including on a small add-file patch. This confirms the issue documented in the earlier 2026-03-07 handoff was not a one-off.

**Lesson**: Do not spend time retrying `apply_patch` in this environment. Use small direct workspace writes, then read back files and run validation immediately.

### Exact-string replacement is brittle in long docs

A first pass at bulk-editing `README.md` failed because the replacement block did not match exactly. Switching to smaller anchor-based insertions was more reliable.

**Lesson**: For repo docs with typographic characters or previous edits, use shorter anchors and multiple deterministic replacements rather than one large block replacement.

### Concurrent work must be treated as real context, not noise

mg explicitly noted that another agent added diagrams. Those changes were not part of the files modified in this session, but they are part of the live worktree context now.

**Lesson**: If another agent's work is mentioned, successors should inspect it before doing adjacent documentation or audience-experience work. Do not assume the current handoff alone captures the whole state.
