## Mistakes and Lessons

1. **The agent failed its own onboarding and didn't notice.** When `Glob` with pattern `agent/handoff-*.md` returned no results (because it searched from the Cowork working directory, not the repo root), the agent concluded "no handoff files exist yet (likely archived)" and moved on. This is exactly the silent failure the onboarding repair now guards against. Root cause: relative paths in onboarding-core.md combined with Cowork's non-repo-root cwd. The agent had a ready-made rationalization (the archive instruction in step 4) and didn't question the search itself.

2. **`Glob` vs. `ls` matters in Cowork.** The `Glob` tool defaults to cwd when no path is specified. In Cowork, cwd is `/sessions/<session-id>/`, not the repo root at `.../mnt/cyberneutics/`. A bare `ls agent/` with the right base path would have found the files immediately. Successors in Cowork should always use explicit absolute paths or verify their working context before using pattern-matching tools.

3. **The prompt file was read before completing onboarding.** The agent read `onboarding-core.md` and the prompt file in parallel (both requested by mg). This meant the prompt analysis was done without the context from the handoff or project-state. The analysis was adequate for a first-pass summary but would have been richer with full context. Lesson: complete onboarding steps sequentially even when the user's request seems to invite parallelism.
