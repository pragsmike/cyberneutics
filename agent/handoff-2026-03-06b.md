## Theoretical/Conceptual Notes

- **The session surfaced a second class of LLM-as-reviewer error.** The previous session identified *concept-instance conflation* (collapsing an abstract principle into its dominant example). This session identified *false synonymy* (treating distinct concepts as interchangeable because they co-occur in similar textual contexts). Both are instances of the same underlying dynamic: LLMs weight by co-occurrence and textual proximity rather than by conceptual role in the framework. The review prompt now guards against the first class (Conceptual Hierarchy bullet) but not the second.

- **The terminology is precise and the precision matters.** "Narrative engine" (what the tool is), "stochastic imps" (what you're up against), "statistical ghost" (what the encounter feels like), "game within the game" (the strategic response) — these are four nodes in the conceptual framework with distinct roles. Collapsing any pair loses information. This is exactly the kind of precision that LLM reviewers will erode if the review prompt doesn't explicitly protect it.
